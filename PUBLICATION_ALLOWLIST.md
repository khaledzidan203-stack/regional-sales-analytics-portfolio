# Publication Allowlist

Only reviewed, portfolio-safe material may be published. Inclusion on this list does not bypass sanitization or validation.

Allowed after review:

- Generic documentation and diagrams
- Sanitized V12 analytical source
- Sanitized Tauri and Rust source
- Architecture diagrams and empty-state screenshots after review
- Public build and installation instructions
- Technical and desktop architecture documentation
- KPI, LFL, Recovery, Delivery Channel, and Data Quality methodology
- Excel export documentation
- Tests and validation scripts
- Package metadata and lockfiles after review

Tests may use small in-memory objects or temporary files deleted during the test. No real, synthetic, dummy, or generated business dataset is allowed. Nothing from the private source project is copied automatically; every curated item must pass the manifest and publication gates.
