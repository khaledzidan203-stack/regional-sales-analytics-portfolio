# Final Release Validation

## Release scope

This hardening release improves public presentation, formula regression coverage, evidence boundaries, publication governance and CI clarity while preserving the generalized 18-page analytical source and data-free publication model.

## Automated validation

The repository quality gate checks:

- required source/document structure;
- application version consistency;
- 18 `PAGE_META` entries;
- 18-page documentation catalog parity;
- JavaScript syntax;
- offline-safe generated frontend;
- required local vendor dependencies;
- source/app SHA-256 generation manifest;
- generated frontend reproducibility;
- weighted AST;
- zero-denominator handling;
- budget-gap logic;
- partial-month budget proration helper;
- LFL formula;
- strict-comparable boundary rules;
- recovery scenario calculations;
- Delivery non-double-counting invariant;
- temporary XLSX workbook structure;
- forbidden business-data artifacts;
- prohibited binaries/archives;
- broken Markdown links;
- privacy-sensitive terminology;
- credentials, private paths, internal networks and embedded branding.

## Runtime boundaries

- Generalized HTML/CSS/JavaScript analytical engine: implemented.
- Generated offline frontend: implemented and reproducibly validated.
- XLSX processing/export: implemented in source.
- Tauri/Rust desktop packaging source: implemented.
- Windows NSIS binary build in CI: not claimed.
- SQL: engine-neutral analytical reference.
- Power BI: design/mapping only.
- Business data: intentionally not committed.
- Business-result screenshots: intentionally not committed.
