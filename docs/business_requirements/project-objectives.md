# Project Objectives

- Integrate daily sales, monthly budget, branch master, and optional delivery-component inputs in memory.
- Centralize formulas so KPIs, visuals, tables, insights, and exports reconcile.
- Support both stable comparable scope and total-region scope.
- Keep weighted ratios mathematically correct at every aggregation level.
- Provide configurable Pre/Post Recovery analysis without presenting association as causation.
- Prevent double counting of an embedded component channel.
- Make data readiness visible before analytical interpretation.
- Deliver the same frontend in a browser and a reproducible offline Windows desktop shell.
- Keep all business datasets outside the public repository.
