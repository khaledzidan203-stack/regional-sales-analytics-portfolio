# Desktop Release Policy

The existing private executable and installer are not public artifacts and must never be copied into this repository or a GitHub Release.

A future public installer is permitted only after a portfolio-safe rebuild, ephemeral-fixture testing, publication and binary scans, a clean-machine installation test, WebView2 verification, installer-content review, and approval of the exact release checksum.

Until every gate passes, documentation may describe the NSIS architecture but must not distribute a binary.
