# Like-for-Like Methodology

For each selected current date, the engine selects the same calendar date one year earlier. It then aggregates the chosen measure only after scope and filters are applied.

```text
LFL Growth = (Current Period - Same-period LY) / Same-period LY
```

The calculation supports Total Sales, Core Retail, Service Channel, Customer Count, and weighted AST. Outputs include daily, weekly, monthly, cumulative, and branch-level views. Weekly and monthly presentation is derived from the same aligned date sets; it does not introduce a separate comparison base.

New branches and branches closed before the end of either comparison window are excluded in Strict Comparable scope. Total Region follows current filters and therefore reflects openings, closures, and other network change.

LFL describes change under a declared comparison scope. It does not establish why that change occurred.
