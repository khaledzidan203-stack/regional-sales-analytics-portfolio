# Strict Comparable vs Total Region

## Strict Comparable Branches

A branch must be available across both aligned windows. Opening dates must not fall after either window begins, and closure dates must not fall before either window ends. This reduces lifecycle distortion and answers: “How did the stable operating base perform?”

## Total Region / Current Filters

All records matching the active filters are included. New and closed branches can affect the result. This answers: “How did the selected network perform in total?”

Both scopes use identical date alignment and formulas. The difference is membership, not arithmetic. Reports and exports label the selected scope because the two results answer different business questions.
