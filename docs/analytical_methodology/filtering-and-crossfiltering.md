# Filtering and Cross-filtering

## Global controls

Year, Month, Week, Date From, Date To, City, Branch, Delivery Branches, Status, Category, and Size Group define the active analytical context. Year, month, week, city, branch, status, category, and size use searchable multi-select controls. Branch options cascade from broader filters.

## Chart selections

Chart clicks map visual values back to fields such as date, month, week, city, branch, category, size, lifecycle status, segment, Recovery period, Delivery scenario, or Data Quality issue. The mapping is declared centrally rather than embedded in each chart's calculation.

Active-filter chips show global and chart-driven selections. A user can clear one visual selection, one slicer, or all chart filters without silently changing unrelated context. Export metadata records the selected filter scope.
