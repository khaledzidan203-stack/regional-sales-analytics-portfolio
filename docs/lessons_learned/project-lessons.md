# Project Lessons

- Centralized logic keeps KPIs, visuals, tables, insights, and exports reconciled.
- Charts must consume results rather than become independent data sources.
- Weighted ratios aggregate numerator and denominator before division.
- Comparable membership changes LFL meaning even when arithmetic is identical.
- Embedded component channels must not be added to parent sales twice.
- Recovery scenarios support decisions but do not prove causality.
- One authoritative source and reproducible desktop generation reduce drift.
- Local vendoring improves offline desktop reliability.
- Public artifacts must be rebuilt from generalized source, never copied from private output.
- In-memory tests demonstrate formulas without publishing datasets.
